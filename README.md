# 爱分你 · 盒子里的小小画展

用户体验设计课程的交互概念原型，非爱分你官方发布。使用样例画作及示例作品名、作者署名和故事。

## 本地查看

打开 `index.html`。图片、字体、样式和脚本均随项目提供。支持作品视图切换、放大、故事展开、公益项目介绍、完成反馈、礼盒/封套切换及图片下载。

## GitHub Pages

本项目为无构建步骤的静态站点。仓库上传完成后，在 Settings → Pages 中选择 Deploy from a branch，选择 main 分支与根目录并保存。`.nojekyll` 保留静态文件原样发布。

正式网址必须以 Pages 实际部署结果为准，不推测可用性。部署成功后需在关闭代理的环境及手机网络中测试，再将封套/礼盒二维码替换为通过验证的实际网址并重新导出图片。当前二维码编码 GitHub Pages 目标地址；发布后须验证实际访问情况。

## 访问与素材

页面带 noindex/nofollow/noarchive 标记，减少搜索引擎收录；这不是私密访问控制。公开仓库的代码与素材可被访问。
